# FF14 潛水艇工具箱

《Final Fantasy XIV》潛水艇部件製作計算機。選擇目標部件後，輸入當前庫存，即可得知還差哪些原始素材。

## 功能介紹

### 成品
- 依艦級（鯊魚級、甲鱉級…）分組顯示可製作的部件按鈕
- 點擊按鈕新增目標；已選擇的部件會變灰，避免重複加入
- 點擊 × 移除單一目標

### 當前庫存
依三層素材架構分欄顯示，並在輸入庫存數量後即時更新剩餘：

| 欄位 | 說明 |
|------|------|
| **Lv2 半成品** | 成品直接需求的高階中間素材，顯示目標數量與剩餘 |
| **Lv1 半成品** | 製作 Lv2 所需的中間素材；若非直接素材則標記 `*`，目標與剩餘欄顯示 `-` |
| **基礎素材** | 無法再拆解的原始素材，僅輸入現有數量 |

> `*`：過渡半成品，非直接素材，不計入等價基礎素材目標

### 等價基礎素材
- 將所有庫存（半成品 + 基礎素材）換算成等值的原始素材數量
- 顯示**數量 / 目標 / 剩餘 / 進度百分比**，一目了然還差多少

## 三層素材架構

```
成品（products）
  └── 半成品 Lv2（recipes, level 2）
        └── 半成品 Lv1（recipes, level 1）
              └── 基礎素材（basicMaterials）
```
